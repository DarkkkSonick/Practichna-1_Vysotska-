1. Що таке перевантаження операторів? Які оператори можна, а які не можна перевантажувати в C#?

Перевантаження операторів у мові C# — це механізм, який дає можливість змінювати стандартну поведінку операторів для власних класів і об’єктів. Завдяки цьому об’єкти можна використовувати у виразах так само зручно, як і звичайні типи даних. У C# дозволяється перевантажувати арифметичні оператори, оператори порівняння, унарні оператори, а також оператори true і false. Водночас не можна перевантажувати оператори присвоєння, логічні оператори && і ||, а також службові оператори, наприклад new чи typeof.

2. Наведіть приклади перевантажених операторів з вашого коду (не менше 6 різних).

У процесі виконання практичної роботи було реалізовано декілька різних перевантажених операторів. У класі StudentGroup оператор + використовувався для об’єднання двох груп студентів. У класі Student були реалізовані оператори порівняння, що дозволяють оцінювати студентів за середнім балом та рівнем успішності. У класі Vector перевантажено оператори +, - і * для виконання математичних дій над векторами. Крім цього, у класі GradePoint реалізовано оператори інкременту та декременту для зміни значення оцінки.

3. Поясніть різницю між явним та неявним приведенням типів. Де ви їх використали?

Неявне приведення типів (implicit) відбувається автоматично, якщо перетворення є безпечним і не призводить до втрати даних. Явне приведення (explicit) виконується вручну за допомогою вказання типу в дужках, коли існує ризик втрати точності або потрібен контроль з боку програміста. У роботі неявне приведення було використано в класі GradePoint для автоматичного перетворення оцінки у тип double під час обчислень. Явне приведення застосовувалось у класі Vector для отримання довжини вектора у вигляді числового значення.

4. Для чого потрібні оператори true та false? Наведіть приклад використання.

Оператори true та false потрібні для того, щоб об’єкти можна було використовувати безпосередньо в умовних конструкціях. Це дає змогу перевіряти стан об’єкта без окремих методів чи додаткових умов. Наприклад, у класі GradePoint оператор true повертає значення істини, якщо оцінка студента є більшою або дорівнює восьми балам. Завдяки цьому об’єкт можна напряму використовувати в операторі if.

5. Як ви реалізували порівняння студентів? Які оператори для цього використовували?

Порівняння студентів було реалізовано за допомогою операторів >, <, >=, <=, а також == і !=. Основним критерієм порівняння виступав середній бал студента. Якщо результати були однаковими, додатково враховувався показник прогресу навчання CourseProgress. Такий підхід дозволив більш точно визначати успішність студентів та формувати рейтинг у групі.

6. Які труднощі виникали при перевантаженні операторів? Як їх вирішували?

Під час виконання роботи виникали труднощі, пов’язані з необхідністю правильної реалізації парних операторів, наприклад == та !=. Також потрібно було забезпечити коректну роботу порівнянь між об’єктами. Для вирішення цих проблем були перевизначені методи Equals і GetHashCode, а також дотримані всі вимоги C# щодо сигнатур операторів.

7. Як перевантаження операторів покращує читабельність коду?

Перевантаження операторів робить код більш зрозумілим і компактним. Замість використання великої кількості методів можна записувати операції у звичному математичному вигляді. Це спрощує сприйняття програми та робить її структуру більш логічною й зручною для інших розробників.

Звіт з практичної роботи №5 
студентка групи К-321  
Висоцька Софія Сегіївна
Питання 1. Наслідування — це механізм об’єктно-орієнтованого програмування, що дозволяє похідному класу успадковувати властивості та методи базового класу для побудови ієрархічних структур. Головними перевагами цього підходу є повторне використання коду та можливість застосування поліморфізму, тоді як основним недоліком є створення жорсткої залежності між класами, де зміни в базі можуть неочікувано вплинути на нащадків. 
Питання 2. У процесі розробки ключове слово base використовувалося в конструкторах для ініціалізації полів базового класу Person через дочірні класи, а також у методах для отримання базової інформації перед додаванням специфічних даних студента. 
Питання 3. Різниця між механізмами virtual/override та new полягає в тому, що перші дозволяють реалізувати динамічний поліморфізм, забезпечуючи виклик правильної версії методу через посилання на базовий тип, тоді як new просто приховує метод батька без участі в поліморфному ланцюжку. 
Питання 4. Абстрактні класи були впроваджені як спільні шаблони, що задають обов'язкові правила для всіх нащадків, як це реалізовано в класах Person та UniversityMember. 
Питання 5. Модифікатор sealed був використаний для класу GraduateStudent, щоб заборонити подальше успадкування від цієї фінальної ланки ієрархії та гарантувати завершеність її логіки. 
Питання 6. Поліморфізм у системі було реалізовано через зміну типу колекції в StudentGroup на базовий тип UniversityMember, що дозволило автоматично викликати специфічні методи розрахунку стипендії для різних категорій студентів. 
Питання 7. Під час проектування ієрархії виникали труднощі з налаштуванням конструкторів та виникненням дублювання властивостей, які були вирішені шляхом чіткої структуризації полів та використання ключового слова base. 
Питання 8. Виконання практичної роботи дозволило глибше засвоїти принципи побудови складних програмних архітектур, навчитися працювати з абстракціями та ефективно використовувати Generic-методи для фільтрації об'єктів.
